# Química y Biología · UNC

Página interactiva basada en las tres unidades del sílabo 2026-II de Química y Biología (código 940218) de la Universidad Nacional de Cajamarca.

Incluye teoría y fórmulas con KaTeX, tabla periódica de 118 elementos, nomenclatura inorgánica (sistemática, Stock y tradicional), introducción a la nomenclatura orgánica, cuestionarios y calculadoras. El progreso se guarda en el navegador.

## Abrir

Abre [la página](https://jhoel13.github.io/quimica/) cuando GitHub Pages indique que la publicación terminó. También puedes descargar el repositorio y abrir `index.html` localmente.

La información elemental ampliada y las fotografías atribuidas se consultan desde [Periodic Bubbles](https://periodicbubbles.com/api/); la tabla básica funciona sin ese servicio. La teoría de nomenclatura sigue las guías de [IUPAC](https://iupac.org/what-we-do/nomenclature/brief-guides/). La tabla periódica se contrastó con [PubChem](https://pubchem.ncbi.nlm.nih.gov/periodic-table/). Para fórmulas tipográficas se usa KaTeX desde CDN.

## Publicación

El workflow `.github/workflows/pages.yml` publica la raíz del repositorio al recibir cambios en `main`. En **Settings → Pages → Build and deployment → Source**, selecciona **GitHub Actions** una vez si todavía no está habilitado.
